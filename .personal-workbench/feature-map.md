# 个人工作台 — Feature Map

## Product purpose

给一个人的「人生操作系统」：每天打开它安排今天，做完记一笔，周末回头看，一年后能翻出自己做过什么。底座 + 模块，本地优先，AI 增强。

## First version

状态：**已确认**（2026-11-02，用户选择全部 16 项 P0；P1 与模块暂不做；提案见根目录 `开发文档.md`）。

P0（必须交付）：

1. 今日总览（今日任务、日程、本周完成率）
2. 任务 CRUD（状态/优先级/截止日/项目/标签）
3. 任务完成与撤销
4. 任务筛选（状态/项目/标签/今天/本周/逾期）
5. 日程（周/日视图、全天事件）
6. 页面内提醒（浏览器通知，页面开着时）
7. 快速记录（任意页面唤起，≤10 秒入库）
8. 记录（Markdown、标签、置顶、归档）
9. 全文搜索（任务 + 记录，类型/时间过滤）
10. 今日复盘（3 问）
11. 周复盘（自动汇总 + 编辑）
12. 数据导出/导入（JSON）
13. 自动备份（每日，保留 14 份）
14. AI 配置（OpenAI 兼容，测试连接）
15. AI 整理记录（人工确认后落库）
16. AI 生成复盘初稿（基于真实数据）

P1（随后 1–2 周）：

17. 自然语言搜索（AI 解析 + 摘要）
18. 任务看板视图（拖拽）
19. `.ics` 日历导入（只读）
20. 重复任务
21. 快捷键体系（⌘K / N / /）
22. 周报导出 Markdown
23. 标签管理（重命名/合并/删除）

## Feasibility

| 能力 | 标签 | 条件 / 限制 |
|---|---|---|
| 任务、日程、记录、复盘、搜索 | ✅ Direct | 本地 SQLite + FTS5 即可 |
| 页面内浏览器通知 | ✅ Direct | 页面开着、用户授权通知权限 |
| AI 整理/生成/搜索 | ⚠️ User action | 需要用户提供 API key（或本地 Ollama） |
| 关页后推送 | ⚠️ Service | 需要部署 + HTTPS + Web Push（V2） |
| 日历导入 `.ics` | ✅ Direct | 只读解析，不双向同步 |
| 多端同步 | ⚠️ Service | 需要服务器或同步服务（部署后） |
| 知识库对接 | ⚠️ Service | 需用户先建知识库并提供 API/导出 |
| 自动抓取外部平台数据 | ❌ Unreliable | 无稳定合法接口，不做 |

## Later / out of scope

以后（模块化）：习惯打卡、记账、学习目标、自媒体选题库、项目看板、阅读清单、心情日记、健康记录、Web Push、多端同步、知识库对接。

V1 不做：登录/多用户、云同步、原生 App、团队协作、支付/发票、甘特图/OKR、外部平台自动抓取。
