# 个人工作台 — Workflow

## Current workflow

（基于访谈推断，待用户用真实一天校正）

- 任务/待办：想到什么记在微信文件传输助手、备忘录或脑子里；没有统一收件箱。
- 日程：靠日历 App 或记忆；提醒靠手机通知，工作内容不在一处。
- 记录：工作进展写在聊天记录/文档里，想法散落在备忘录；找的时候靠翻聊天记录。
- 复盘：周报/复盘从零开始写，耗时且容易拖。
- 学习：课程资料、笔记分散，学完没有归档机制，过后想不起来。
- 副业/自媒体：选题、进度、数据没有固定载体。

## Friction and handoffs

- 重复录入：同一件事在聊天、备忘录、表格里各记一遍。
- 找不到：关键词在哪个 App 里不确定。
- 忘记：没有统一提醒，截止日和约会靠记忆。
- 不透明：项目一多，不知道每个进展到哪。
- 从零写：复盘/周报没有素材积累，写起来痛苦。
- 沉淀断裂：学过的东西没有结构化留存，无法复用。

## Proposed improved workflow

一个闭环，四步：

1. **早上（2 分钟）**：打开「今日」→ 看到今天必须做的 3 件事 + 今日日程。
2. **白天（随时）**：`⌘K` 或悬浮按钮「快速记录」，一句话入库（10 秒）；做事时在任务里记进展。
3. **做完（即时）**：任务打勾，自动记录完成时间；未完成的自动滚到明天/本周。
4. **晚上/周末（5 分钟）**：今日 3 问复盘；周复盘自动汇总本周数据 + AI 初稿 → 你改 3 句 → 保存/导出。

支撑能力：

- 搜索：`⌘K` 全文搜任务 + 记录，按类型/时间过滤。
- 整理：收件箱里的乱记，用 AI 一键变成结构化任务/记录（你确认才保存）。
- 沉淀：记录可打标签、可置顶、可关联外部知识库条目（接口预留）。
